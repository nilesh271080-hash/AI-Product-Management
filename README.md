# AI Product Management

My home base for AI product management work: the frameworks, skill packs, and notes I use day to day.

## PM skills for Claude Code

The skill pack referenced from this repo is **The Complete Claude Guide for Product Managers** by **90n**: 42 Claude skills covering the whole product job in eight stages, from vision to the weekly update. The skills are 90n's work, not mine. This repo contains no copies of the skill files. Install them from 90n's marketplace and they load in Claude Code.

- Guide: https://90n.ai/resources/complete-claude-guide-for-product-managers-pack
- Source repo: https://github.com/polar-bear-org/claude-skills
- Pack: `packs/complete-claude-guide-for-product-managers-pack` (plugin `complete-claude-guide-for-product-managers-pack`, marketplace `90n-skills`, version 1.0.0)

### Install (Claude Code)

```
/plugin marketplace add polar-bear-org/claude-skills
/plugin install complete-claude-guide-for-product-managers-pack@90n-skills
```

See [PM-SKILLS-INDEX.md](PM-SKILLS-INDEX.md) for all 42 skills, grouped by stage, with what each one produces.

### Ground rules the pack itself sets

- Real customers are not optional: Claude drafts the documents, the team talks to users, and a named person makes the call.
- No invented facts: a missing figure becomes a bracketed placeholder or an open question.
- Work is scored, people are not.
